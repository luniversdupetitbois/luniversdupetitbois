Animations

  • Apparition au scroll : légère montée + fondu (translateY 20px → 0, opacité 0 → 1), 0.6–1s, jamais plus.
  • Survol des cartes : translation vers le haut de 5-6px + ombre qui s'intensifie, transition 0.3s.
  • Survol des photos de catégorie : léger zoom (scale 1.08), transition 0.5s.
  • Boutons : translation vers le haut de 2px au survol, transition 0.2s.
  • Toujours respecter prefers-reduced-motion : couper les animations pour les visiteurs qui le demandent.

Comment utiliser ce guide

Ce fichier n'est pas qu'une démo visuelle : les variables CSS (:root) en haut du fichier sont exactement celles utilisées sur le site. Pour garder la cohérence en ajoutant une page :

  • Toujours partir de ces couleurs, jamais de nouvelles teintes inventées à la volée
  • Toujours utiliser Cormorant pour les titres, Karla pour le texte
  • Réutiliser les rayons, ombres et espacements de cette page plutôt que des valeurs arbitraires
  • Un nouveau développeur (humain ou IA) peut copier ces variables telles quelles dans n'importe quelle nouvelle page du site
